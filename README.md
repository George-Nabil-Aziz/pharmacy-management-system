# Pharmacy Management System

Multi-branch, multi-organization pharmacy management system for the Egyptian market.

**Planned stack:** ASP.NET Core (.NET 10) modular monolith with Clean Architecture, EF Core, PostgreSQL 17 (row-level security from the MVP), React + TypeScript + Vite, i18next (Arabic RTL / English).

**Status:** documentation phase complete; implementation has not started. Start with [docs/README.md](docs/README.md).

- 10 specifications, 223 user stories, 1,231 test cases
- MVP scope and phased roadmap: [docs/roadmap/](docs/roadmap/)
- Implementation plan: [docs/superpowers/plans/](docs/superpowers/plans/)
