# Phase 0 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the walking skeleton. It has the .NET 10 modular-monolith solution, the cross-cutting building blocks (money, errors, tenant context with PostgreSQL RLS enabled from the first migration, idempotency, outbox + same-transaction audit, gapless document numbers), the React/TypeScript shell with Arabic/English and themes, and CI.

**Architecture:** One ASP.NET Core host composes modules that follow Clean Architecture (Domain/Application/Infrastructure/Contracts). Cross-cutting concerns live in `src/BuildingBlocks/*`. Every tenant-owned table carries `organization_id` and is protected by EF Core global filters **and** an enabled, forced RLS policy that reads `current_setting('app.organization_id')`. A connection interceptor sets that value with `SET LOCAL` per transaction.

**Tech Stack:** .NET 10, ASP.NET Core minimal APIs, EF Core 10 + Npgsql, PostgreSQL 17, FluentValidation, Serilog, xUnit v3, FluentAssertions, Testcontainers.PostgreSql, NetArchTest.Rules, React 18 + TypeScript + Vite, i18next, Tailwind CSS, Zustand, TanStack Query, Vitest + React Testing Library, Docker Compose, GitHub Actions.

## Global Constraints

- Target framework `net10.0`; `Nullable` enabled; `TreatWarningsAsErrors` true; central package management (`Directory.Packages.props`).
- PostgreSQL 17. Every tenant-owned table: `organization_id uuid NOT NULL`, `ENABLE ROW LEVEL SECURITY`, `FORCE ROW LEVEL SECURITY`, and a policy on `current_setting('app.organization_id', true)::uuid`. These are created **in the same migration** as the table (ADR-002 amended 2026-11-10).
- The application connects as role `pms_app` (no `BYPASSRLS`, not table owner). Migrations run as `pms_owner`.
- Money: C# `decimal`, PostgreSQL `numeric(19,4)` for unit prices/costs and `numeric(19,2)` for document amounts, `MidpointRounding.AwayFromZero` (BR-G-18).
- IDs: UUIDv7 generated by the application (`Guid.CreateVersion7()`).
- Errors: RFC 9457 Problem Details with extensions `code`, `traceId`, `errors` (API-DESIGN §5).
- Idempotency header `Idempotency-Key` (UUID); records kept 24 h keyed by (organization, user, key) with a SHA-256 request hash. Same key with a different hash → 422 `COMMON.IDEMPOTENCY_KEY_REUSED`; missing key on a required endpoint → 428 `COMMON.PRECONDITION_REQUIRED`.
- Timestamps `timestamptz` UTC. Business date from branch time zone (default `Africa/Cairo`) via `TimeProvider`.
- Frontend: TypeScript `strict`; every UI string from i18next (`en`, `ar`); `dir="rtl"` for Arabic; Tailwind logical properties only (`ms-*`/`me-*`, not `ml-*`/`mr-*`).
- **No git repository exists yet (product-owner decision 2026-11-10).** Commit steps apply once the owner approves `git init`. Until then, skip the commit step and keep the checklist.

namespace Pharmacy.BuildingBlocks.Domain;

public readonly record struct Money(decimal Amount)
{
    public static readonly Money Zero = new(0m);
    public static Money Of(decimal amount) => new(amount);
    public Money RoundToDocument() => new(decimal.Round(Amount, 2, MidpointRounding.AwayFromZero));
    public static decimal RoundUnit(decimal value) => decimal.Round(value, 4, MidpointRounding.AwayFromZero);
    public static Money operator +(Money a, Money b) => new(a.Amount + b.Amount);
    public static Money operator -(Money a, Money b) => new(a.Amount - b.Amount);
    public static Money operator *(Money a, decimal quantity) => new(a.Amount * quantity);
}

using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Mvc;
using Pharmacy.BuildingBlocks.Domain;

namespace Pharmacy.BuildingBlocks.Web;

public static class ProblemDetailsMapping
{
    public static int StatusFor(ErrorKind kind) => kind switch
    {
        ErrorKind.Validation => StatusCodes.Status400BadRequest,
        ErrorKind.Forbidden => StatusCodes.Status403Forbidden,
        ErrorKind.NotFound => StatusCodes.Status404NotFound,
        ErrorKind.Conflict => StatusCodes.Status409Conflict,
        ErrorKind.PreconditionFailed => StatusCodes.Status412PreconditionFailed,
        ErrorKind.Unprocessable => StatusCodes.Status422UnprocessableEntity,
        ErrorKind.PreconditionRequired => StatusCodes.Status428PreconditionRequired,
        _ => StatusCodes.Status500InternalServerError,
    };

    public static ProblemDetails ToProblem(Error error, HttpContext ctx)
    {
        var problem = new ProblemDetails { Status = StatusFor(error.Kind), Title = error.Message };
        problem.Extensions["code"] = error.Code;
        problem.Extensions["traceId"] = ctx.TraceIdentifier;
        if (error.FieldErrors is not null) problem.Extensions["errors"] = error.FieldErrors;
        return problem;
    }

    public static IResult ToHttpResult(Error error, HttpContext ctx)
    {
        var p = ToProblem(error, ctx);
        return Results.Problem(p.Detail, statusCode: p.Status, title: p.Title, extensions: p.Extensions);
    }
}

CREATE SCHEMA IF NOT EXISTS org;
CREATE TABLE org.branches (
    id uuid PRIMARY KEY,
    organization_id uuid NOT NULL,
    code varchar(10) NOT NULL,
    name varchar(200) NOT NULL,
    created_at timestamptz NOT NULL DEFAULT now(),

ALTER TABLE org.branches FORCE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON org.branches

using Npgsql;
namespace Pharmacy.BuildingBlocks.Infrastructure.DocumentNumbers;

public static class DocumentNumberService
{
    // Row lock held until the caller's transaction ends: rollback releases the value -> gapless.
    public static async Task<string> NextAsync(NpgsqlConnection conn, NpgsqlTransaction tx, Guid organizationId,
        Guid branchId, string branchCode, string docType, int year)
    {
        const string sql = """
            insert into org.document_sequences(organization_id, branch_id, doc_type, year, last_value)
            values (@o, @b, @t, @y, 1)
            on conflict (organization_id, branch_id, doc_type, year)
            do update set last_value = org.document_sequences.last_value + 1
            returning last_value
            """;

        cmd.Parameters.AddWithValue("o", organizationId); cmd.Parameters.AddWithValue("b", branchId);
        cmd.Parameters.AddWithValue("t", docType); cmd.Parameters.AddWithValue("y", year);
        var n = (int)(await cmd.ExecuteScalarAsync())!;
        return $"{branchCode}-{docType}-{year}-{n:D6}";
    }

`IdempotencyFilter.InvokeAsync`:
1. Read the `Idempotency-Key` header and validate it as a GUID. If missing, return 428 `COMMON.PRECONDITION_REQUIRED`.
2. Buffer the request body and compute SHA-256 (hex).
3. Inside the request transaction, run `insert … on conflict do nothing returning`. If it inserted, call `next`, capture the status and body, update the record, and return the result.
4. If a record exists with the same hash and a stored response, replay the stored status and body.
5. If a record exists with the same hash and no stored response, it is in flight: return 409 `COMMON.REQUEST_IN_PROGRESS`.
6. If a record exists with a different hash, return 422 `COMMON.IDEMPOTENCY_KEY_REUSED`.

A Hangfire job `platform.idempotency-cleanup` (Phase 0 Task 0.9 registers it) deletes rows older than 24 h.
