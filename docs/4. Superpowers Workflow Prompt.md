# 4. شكل العمل باستخدام Superpowers

قبل توليد باقي الملفات، لازم Superpowers يراجع المستندات الأساسية (Project Vision، Master SDD، Specs & Stories Roadmap).

## Superpowers Workflow

1. **Brainstorming**

   مراجعة الرؤية، اكتشاف المتطلبات الناقصة، وتحديد القرارات المعمارية.

2. **Specification Design**

   تفصيل كل Spec إلى متطلبات وظيفية وغير وظيفية وقواعد عمل.

3. **Story Design**

   كتابة User Stories صغيرة مع Acceptance Criteria وDependencies.

4. **Writing Plans**

   تحويل كل Story إلى خطة تنفيذ مفصلة بترتيب الملفات والاختبارات.

5. **Test-Driven Development**

   كتابة الاختبارات قبل تنفيذ الـ Business Logic.

6. **Verification**

   تشغيل الاختبارات والتحقق من النتيجة قبل اعتبار أي Story مكتملة.
